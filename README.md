# cmchen-u-agent · U 盘便携 AI Agent

> 插上 U 盘，双击即用。把一个带文件操作、命令执行、联网搜索、git、子 agent 的 AI 助手装进口袋。
>
> **v1.0.0（2026-10-13）**——首个正式版：两轮代码安全审查全数落地、联网搜索三路兜底（Tavily / 通道原生 / 免 key 引擎 + 反爬诱饵过滤）、对话渲染对齐 ZCode 开源实现、218 项测试全绿。

把本目录放进 U 盘，插上任意 **Windows 10/11 x64** 电脑：双击 `启动U-Agent.bat`，浏览器自动打开本地聊天页，agent 就能操作那台电脑上的文件。所有环境、配置、会话数据全部留在 U 盘目录内——宿主机**零安装、零配置、零残留**，拔盘即走。

## 三步用法

1. **装环境（只做一次）**：双击 `setup-uagent.bat`（需联网，约 1 分钟，自动从 npmmirror 下载便携版 node 22）
2. **首次配置（只做一次）**：双击 `启动U-Agent.bat` → 浏览器打开后先设置启动密码（每次启动都要输）→ 点右上角「设置」→ 选工作区目录、选模型通道并填钥匙（加密保存在 U 盘里，以后永不再配）
3. **日常使用**：插 U 盘 → 双击 `启动U-Agent.bat` → 开聊。换任何电脑都不用重装重配

模型走 OpenAI 兼容接口，内置三协议：**OpenAI Chat Completions / OpenAI Responses / Anthropic Messages**（24 家厂商预设，GLM、DeepSeek、OpenAI、Anthropic、OpenRouter、OpenCode Zen/Go、本机 Ollama 等，填钥匙即用）；没配 key 也能用 **Mock 模式**体验界面。

像 OpenCode Zen / Go 这类**按模型分协议**的网关已经处理好：选中模型自动切协议（Claude 系→Anthropic、GPT/Grok 系→Responses、其余→OpenAI 兼容）、自动带上网关要求的会话标识、把整条接口地址粘进「服务地址」也会自动纠偏；连不上时报错会说清是钥匙、地址还是协议的问题。

## 能力

| 能力 | 说明 |
|---|---|
| 文件 | 列/读/写/局部改/搜索/移动/建目录/删除（删除与覆盖高危） |
| 命令 | cmd 执行（30 秒超时、输出截断、破坏系统命令无条件拒绝） |
| git | status / diff / log / commit / push / pull（在工作区仓库上） |
| 联网 | web_search（优先配了钥匙的 Tavily/Brave；没配就**借当前通道做原生联网搜索**——OpenCode Go 等网关支持，跟聊天共用一把钥匙不用另配；再兜底免 key 引擎 + 反爬诱饵过滤）+ web_fetch 网页转文本（国内直连，国外页面可配代理） |
| 子 agent | spawn_subagent 派生独立子任务，网页里嵌套展示 |
| 多模态 | 对话框直接粘贴/拖入图片提问 |
| 权限五档 | 确认（默认，高危弹窗）· 只读 · 计划 · 自动审批（高危直接拦截）· 完全权限 |
| 细粒度放行 | 七类动作可单独勾选免问：读文件 / 改文件 / 删文件 / 跑安全命令 / 跑任何命令 / 联网 / 派子任务；可设「连续自动几次后回来问我」 |
| 一键撤销 | agent 每次改文件前都留一份原样备份，「本轮改动」卡片上点两下就能把这一轮改过的文件恢复回去；之后被人改过的文件会先拦一下，不闷头覆盖 |
| 回退对话 | 说错话了不用重开会话：鼠标移到你说过的话上点「从这儿重来」，后面那段不再进上下文，被回退的这句放回输入框；文件改动保留（跟「一键撤销」分工互补） |
| 界面 | 模型与权限选择器就在输入框那一行（跟 Cursor/OpenCode 一样的位置），厂商卡用官方图标（16 家内置品牌图形，其余品牌色字母牌，零联网零依赖） |
| 自定义命令与技能 | 在工作区或 U 盘的 `.agent\commands\*.md` 放一条命令、`.agent\skills\<名>\SKILL.md` 放一个技能，写进去就生效——技能是"按需加载"的（平时只占一句话的上下文） |
| 改完自己验 | 配好 test / lint 命令后，agent 改过文件就自动跑；没过就把输出交给它自己修（一轮最多修两次），不用你盯着 |
| 计划→批准执行 | 计划模式下它交上来一份计划，你点「批准执行」才开始动手；不批就写下意见让它接着改 |
| 完成标准（/goal） | `/goal 测试全绿且文档写清楚`：每轮结束时自动判定是否真有实据，没达成它会接着做 |
| 后台任务 | 长构建/长测试/本地服务丢到后台跑（`shell_bg`），状态条上有芯片，能看输出尾巴、能一键停 |
| 看得到思考 | 模型的思考过程单独流式展示（灰字），回复一开始就收成「已思考 N 秒」一行，点开可看全过程；`/thinking` 或设置里可整体关掉 |
| 防跑偏 | 同一条调用连续重复到第 3 次会停下来问一句（防死循环）；审批弹窗上点一下「本会话不再问这类命令」，之后同类命令不再打扰 |
| 说不停就不用停 | 正在跑的时候按回车 = 把话排进队列（可取消、可放回输入框改），这一轮完自动接着说；点发送按钮才是停下 |
| 并行工具 | 一轮里说改几个文件，它们会同时跑（默认 4 路并行），不用一个等一个 |
| 自动压缩 | 上下文涨到 80% 自动用轻量通道把旧对话摘要掉（可在设置里改成 90% 或关闭），不必盯着用量条手动点 |
| 长上下文 | 按模型**真实窗口**算预算（Claude 5 系 / GLM-5.3 / DeepSeek-v4 都是 1000k 级，GPT-5.6 系 1050k）——窗口数据来自 models.dev 目录，认不出或对不上时可在通道里手填 |
| 记忆 | 会话 JSONL 追加日志全存 U 盘 `data\sessions\`；跨会话记忆在 `data\memory.md` |
| 导出 | 对话里输入 `/export` 把当前会话导出成 Markdown |

安全设计：路径沙箱（只允许工作区与 U 盘目录，越界拒绝）、高危操作审批（agent 自己的配置/代码/数据——`.agent`、`data`、`tools`、`core` 等自查面——改动一律强制人工确认）、shell 黑名单（format/shutdown/reg delete 等任何模式都拦，前台后台同一个闸）、抓网页拦内网地址（防 SSRF，重定向逐跳复查）、审计日志（`data\audit.jsonl`：裁决与放行逐条落盘）、用户 hooks 按内容哈希过信任闸（工作区与 U 盘一视同仁）、全套安全响应头（CSP / nosniff / DENY / no-referrer）；启动密码存在盘里 `data\lock.json`（**跟着盘走，换电脑还是这一个密码**，只有全新盘才允许设置），连错 5 次进入指数退避冷却，防别人拿你的盘慢慢试。**首次使用还没设密码之前，本机接口是不设防的——拿到盘第一件事先设密码。**

## 原理与结构

`node.exe`（便携，U 盘内）+ **零 npm 依赖**的 Node 脚本（只用内置模块，FAT32 U 盘免安装免编译）。内核设计参考 [deepseek-ai/deepseek-harness（dsh）](https://github.com/deepseek-ai/deepseek-harness) 的「Agent = Model + Harness、一切皆插件、工具风险审批、会话追加日志」；U 盘打包模式参考 [hermes-portable](https://github.com/yuluyangguang1/hermes-portable)、[portable-agent-usb](https://github.com/bnovik0v/portable-agent-usb) 等同类项目。

```
启动U-Agent.bat   双击入口（%~dp0 相对定位，换盘符免改）
setup-uagent.bat  环境安装（幂等，--force 重装）
launcher.mjs      空闲端口探测(3080→3090) + 起服务 + 开浏览器
server.mjs        本地服务（只绑 127.0.0.1）
core/             主循环·三协议适配·模式门禁·沙箱·确认闸·会话·检查点
tools/            20 个插件工具（fs/shell/git/web/subagent）
public/           网页：index.html + css/app.css + js/{ui,api,state,catalog,picker,theme,chat,settings,notify,app}.js
runtime|data|config.json   运行时与数据（不进 git）
```

## 界面

聊天页：左侧会话列表（可搜索/重命名/删除）、顶栏（会话名 + **运行中 N 秒 · 停止** + 模型/权限面板 + 主题）、中间消息流（用户气泡 + 助手 Markdown/代码块 + **单行工具调用条**（连续调用归一组，点开看参数与完整结果）+ **思考过程块** + 计划进度卡 + 「本轮改动」卡（带一键撤销）+ 高危确认弹窗（带 diff 预览，还能附一句话理由））、底部输入区（拖入或粘贴图片/文本文件，输入 `/` 唤出命令，输入 `@` 提工作区文件并把内容一并带上）。

输入框上方有一条常驻状态条：**当前权限模式**（点了就换）、**自动放行摘要**（勾了高危项会变黄）、**上下文用量**（按这个模型真实窗口算，`12.3k / 750k · 2%`，到 80% 提醒、满了提示压缩）和**压缩按钮**。不用进设置就能看清"它现在能自己干什么、上下文还剩多少"。

顺手的小交互：**↑** 调出上一条输入；粘贴时自动清掉不可见字符（防提示词走私）；页面被切走时，需要你批准、跑完一轮、出错都会发系统通知并让标题闪烁（可在设置 → 通用 → 提醒里关掉）。

设置页是一个全屏面板，左侧分类导航，右侧分区卡：

| 分类 | 能做什么 |
|---|---|
| 通用 | 挑工作区（可视化目录选择器，不用手打路径）、浅色/深色/跟随系统、提醒开关、查看当前这台电脑 |
| 模型 | 内置 24 家厂商预设（国内 / 国外 / 聚合中转 / 本机离线），选厂商 → 只填钥匙 → 挑模型；「测试连接」当场验证、「拉取模型列表」从厂商实时拉取模型名 |
| 权限 | 五档模式单选卡（两列排布，带各自说明）；「自动放行」七项细粒度开关 + 连续次数上限；任何模式都拦不住的底线清单 |
| 记忆 | 跨会话记忆编辑、AGENTS.md 说明 |
| 联网 | 搜索服务钥匙（保存后不回显） |
| 安全 | 改启动密码、改动检查点占用与清空、清空全部会话 |
| 关于 | 版本、工具数、数据位置 |

改动有未保存提示条，保存前会拦住空列表、通道重名这类错误；界面文案不出现技术缩写，一律说人话。

## 排障

- **打开页面一直刷新 / 输完密码就被清空**：说明浏览器缓存里的旧脚本和新页面混了。按 **Ctrl+F5** 强制刷新一次；页面顶部的黄色横幅也会直接告诉你该怎么办（服务若在跑旧版，关掉那个黑色控制台窗口重新双击 `启动U-Agent.bat` 即可）
- 密码表单从设计上就**拒绝浏览器原生提交**：脚本万一没加载成功，点「解锁」不会刷新页面、更不会吞掉你刚输的密码

## 已知限制

- 目标机需能访问所选模型服务（联网）；Mock 模式离线可用；装 Ollama 可完全离线（预置通道已带，模型自备）
- 目标机使用 git 工具需其装有 git；钥匙加密存于 U 盘 `data\vault.bin`（网页里不可见、文件不存明文，但属防偷看级防护，U 盘仍别外借）
- 忘记启动密码：删掉 U 盘 `data\lock.json` 重新设置
- 撤销只覆盖 agent 用文件工具做的改动（命令执行、git 提交产生的副作用撤不了，卡片上会标出来）；单个文件超过 4MB 不做快照，撤销时会如实说明；每个会话最多留 40 个检查点，更老的自动清
- 回退对话只影响上下文与界面显示（旧记录仍留在会话日志里，可追溯），不删除任何文件
- 只支持上面三协议：网关上走 Google 专用接口的模型（如 OpenCode 的 gemini 系）接不了，选中时会直接告诉你换一个；同理个别网关的私有接口也不支持
- 上下文窗口按 models.dev 公开目录匹配（认不出来按 200k；本机 Ollama 这类按 32k、家族值封顶 64k）；跟实际窗口对不上时可在通道卡里手填
- 模型思考会占输出额度（anthropic 协议默认开启，预算取输出上限的 1/4；嫌慢嫌贵可在通道卡里关掉，`/thinking` 只关显示）
- shell 30 秒超时、输出 200KB 截断；只支持 Win10/11 x64
